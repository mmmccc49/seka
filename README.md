# 极简桌面取色工具（Windows 10/11）

## 本次修复与增强
- 修复：取色点击网页会跳转到网页（覆盖层全屏拦截 + 禁止鼠标重放 + 延迟隐藏防回放）。
- 修复：色卡显示稳定（单色/四色都可渲染）。
- 调整：取色取消方式改为“鼠标右键取消”（仍保留 ESC 兼容）。
- 新增：选中 4 个单色色卡可合并为 1 个多色色卡。
- 新增：色卡右键支持重命名。
- 移除：删除历史记录功能按钮。

## 核心功能
- 屏幕取色流程：`开始取色 -> 隐藏主窗口 -> 十字光标 + 放大镜实时跟随 -> 左键锁定 -> 复制 -> 恢复窗口`
- 鼠标右键取消取色（ESC 仍可取消）
- 自动刷新最后取色 + 历史记录（最近 10 条，点击可复制）
- 颜色显示：HEX / RGB / HSL
- 复制格式选择：HEX / RGB / HSL
- 配色卡：支持 4 色卡、单色卡、4单色合并
- 导出配色卡：TXT / JSON
- 托盘常驻、托盘菜单、双击恢复
- 全局快捷键：`Ctrl+Shift+C`

## 运行
1. 安装 Python 3.10+
2. 安装依赖
   ```powershell
   pip install -r requirements.txt
   ```
3. 启动
   ```powershell
   python main.py
   ```
