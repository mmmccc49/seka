# ColorMark Studio - 桌面取色与配色卡工具

ColorMark Studio 是一个面向 Windows 10/11 的轻量桌面取色工具，支持屏幕取色、连续取色、图片主色分析、配色卡管理和多格式导出。适合 UI 设计、前端开发、品牌色整理和日常配色参考。

## 核心功能

- 屏幕单色取色：取色后自动复制为当前设置的格式。
- 连续取色：一次最多采集 4 个颜色，可提前结束并生成配色卡。
- 实时取色浮层：显示放大镜、HEX/RGB/HSL、已取色进度和已选颜色块。
- 图片主色分析：拖入图片、选择图片或从文件夹中选择图片，自动提取 8 种主色。
- 主色生成色卡：从图片提取结果中选择 1 到 4 种颜色加入色卡库。
- 自动搭配色卡：根据最后一次取色生成 4 色高级搭配。
- 色卡管理：搜索、选中、复制、重命名、删除、合并、复制选中色卡。
- 稳定色卡 ID：色卡内部使用唯一 ID 管理，重名也不会影响选中、删除和重命名。
- 历史记录：保留最近 10 次取色结果，点击即可按当前格式复制。
- 多格式复制：支持 HEX、RGB、HSL。
- 多格式导出：支持 TXT、JSON、CSS Variables、Tailwind、Figma Tokens、ASE。
- 托盘运行：关闭窗口时可选择最小化到托盘或退出程序。
- 主题与快捷键：支持月白/暗黑主题，支持自定义全局快捷键。

## 取色操作

点击右侧的 `单色取色` 或 `连续取色` 进入全屏取色模式。

取色浮层快捷操作：

- 左键：采集当前颜色。
- 右键：单色模式取消；连续模式中已有颜色时提前完成。
- `Esc`：取消取色。
- `Space`：锁定/解除锁定当前采样点。
- 鼠标滚轮：调整放大镜大小。
- `Backspace` 或 `Delete`：撤销连续取色中的上一个颜色。
- `Enter`：连续取色中提前完成。

## 色卡管理

主界面左侧是配色卡工作区：

- 搜索框可按色卡名称或颜色值过滤。
- 点击色卡可选中，同时复制该色卡的第一个颜色。
- 右键色卡可复制单个颜色、复制整张色卡、重命名或删除。
- `按最后取色生成色卡` 会把最后一次取色批次加入色卡库。
- `生成搭配色卡` 会根据最后一次取色生成 4 色搭配方案。
- `合并选中色卡` 可将多个选中色卡合并为一张最多 4 色的色卡。
- `复制选中色卡` 会复制选中的色卡并生成新 ID。
- `删除选定配色卡` 会删除当前选中的色卡。

## 图片主色分析

点击 `上传图片 分析主色` 打开图片分析窗口。

支持：

- 拖拽图片到窗口。
- 从文件选择图片。
- 选择文件夹后从其中的图片列表里挑选。
- 自动识别常见图片格式。
- 从提取出的 8 种主色里选择 1 到 4 种生成配色卡。

## 导出格式

色卡库可导出为：

- `TXT`：适合快速查看和分享。
- `JSON`：保留色卡结构，方便二次处理。
- `CSS Variables`：生成 `:root` 变量。
- `Tailwind`：生成 Tailwind 扩展色板配置。
- `Figma Tokens`：生成可导入设计 token 的 JSON。
- `ASE`：供 Adobe 系列软件使用。

## 设置

设置窗口支持：

- 切换主题：月白 / 暗黑。
- 启用或禁用全局快捷键。
- 自定义快捷键，例如 `Ctrl+Shift+C`、`Ctrl+Alt+Q`、`Alt+F2`。

快捷键支持 `Ctrl` / `Shift` / `Alt` 与字母、数字或 `F1` 到 `F24` 组合。

## 数据存储

应用状态会保存在用户目录下：

```text
%USERPROFILE%\.apple_min_color_picker\color_picker_state.json
```

保存内容包括：

- 色卡列表
- 色卡唯一 ID
- 历史记录
- 最后一次取色
- 复制格式
- 主题
- 全局快捷键设置

## 运行方式

1. 安装 Python 3.10 或更高版本。

2. 安装依赖：

   ```powershell
   pip install -r requirements.txt
   ```

3. 启动应用：

   ```powershell
   python main.py
   ```
